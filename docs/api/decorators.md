## log

**Тип:** function

**Кратко:** Декоратор для логирования вызовов функций.

### Полная документация

```python
Декоратор для логирования вызовов функций.

Args:
    filename: Путь к файлу лога. Если None - вывод в консоль.

Returns:
    Декоратор функции.

Example:
    @log()
    def my_func():
        pass

    @log(filename="logs/app.log")
    def another_func():
        pass
```
